# TaskMint Survey Bot

TaskMint Survey Bot is a Telegram bot built with Node.js, Firebase, and CPX Research.

## Features

- CPX Research Surveys
- Automatic survey rewards
- Referral system
- Daily bonus (7 days)
- Wallet
- Withdrawal requests
- Admin dashboard
- Broadcast messages
- Maintenance mode
- Transaction history
- Railway deployment

## Requirements

- Node.js 20+
- Firebase Firestore
- Telegram Bot Token
- CPX Research Publisher Account

## Installation

```bash
npm install
```

## Start

```bash
node bot.js
```

## Deploy

Deploy easily on Railway.
